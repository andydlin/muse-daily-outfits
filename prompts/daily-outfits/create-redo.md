# Daily Outfits — Create & Redo (consolidated V2)

**Read with:** ../shared/jolly-character.md, ../shared/cubby-lighting.md, ../shared/plush-materials.md

## Before generating
1. Ask/offer a concrete scene plan (pose, main action, mini environment, lighting/effects) and **wait for user approval** even if an outfit reference is supplied.
2. Attach outfit/theme references plus **`MASTER_Jolly_Face_Jett.png` (primary face)** and **`MASTER_Cubby_Bulbasaur.png` (primary cubby)**. Supporting references are **`MASTER_Jolly_Face_Secondy_Goku.png` (secondary face)** and **`MASTER_Cubby_Secondary_Link.png` (secondary cubby)**; primary wins within each role.
3. Apply the shared handmade material standard. **`MASTER_Texture_Mechanic.png` is primary texture only as proposed/conditional**, requiring explicit approval for the current material pass; **`MASTER_Texture_Secondary_Sylveon.png`** supplies compatible secondary texture detail only. Neither silently changes the default standard or authorizes material changes in a redo.
4. Always use **“inspired”** in the character/theme descriptor.

## Create — template

Create **ONE individual square Gizmo's Wall image**: **[CHARACTER] inspired — [SCENE]**.

**Approved scene plan:** [INSERT APPROVED POSE, GESTURE, ACTION, GROUND, SCENERY, CAMERA AND EFFECT NOTES].

Produce a premium photorealistic 3D handmade plush miniature diorama, with a recognizable compact Muse Jolly mascot. Apply the FULL attached Jolly identity standard: broad smooth finely velvety cream inset face separate from fluffier cream framing fur, small spaced black bead eyes, soft blush, tiny simple mouth, no anatomical ears, compact body. Outfit details come from the supplied costume references; never adopt their 2D art/rendering style. Costume hair is dimensional textile tufts, never flat. Creature-hood eyes/features are embroidered **on the hood**, leaving Jolly's face visible.

Apply the shared tactile miniature material standard across costume, environment and props. Use the same complete, rigid, beveled sharp-cornered square peach/ivory cubby, exterior wall, soft shadow, recessed interior depth, and **small thin flush-centered warm-white ceiling LED** found in the approved daily gallery reference. Keep all four outer frame edges visible, consistent square margins, lighting softness and natural depth. Keep magical effects readable, not overblown.

**Do not include** Meta branding, text, titles, numbering, plaques, labels, checklist, UI controls or any progress overlay in the image. Return the single image, not a collage or side-by-side.

## Redo — template

**EDIT THE PROVIDED EXISTING IMAGE, not a new scene.** Subject: [CHARACTER] inspired — [SCENE].

**Requested changes only:** [EXACT EDITS].

Maintain the approved Jolly identity, clothing, action, gesture, cubby and visual material style. Keep all unrelated elements **as unchanged as possible**, including face if not requested, outfit, hair, prop locations, camera, framing, lighting, background and effects. Recolor only via the dedicated recolor workflow. Show one revised image; no comparison unless requested.

## After output

Keep any scene checklist **in chat, not inside the image**. If presenting Create/Redo checklist controls, they must copy editable prompts **without automatically sending them** or launching image generation.
