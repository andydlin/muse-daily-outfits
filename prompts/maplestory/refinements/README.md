# Component prompt library
Approved 2026-11-27. Read the [master prompt](../hero-generation-prompt.md) and [style guide](../hero-style-guide-v0-1.md). Component prompts supplement, never override, canonical standards. [Facial refinement](facial-refinement.md) is the first experimental reusable template. Hair and material templates are reserved for future approved publication; do not treat placeholders as approved prompts. Save authored resolved instructions, master and component revisions, references, crop/mask, approval, output identifiers, deviations and evaluation in [generation records](../generation-records/README.md). Record before generation and append results afterward. Historical reconstructions must be labeled; hidden generator rewrites are not available. Notify user of reusable changes, obtain approval, commit and verify before use. One image per approved step.
