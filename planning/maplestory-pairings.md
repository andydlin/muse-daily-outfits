This is a pairing-only record. Artwork-generation references are supplied in separate chats. The **website renders directly from the canonical JSON**, so changes to the data appear automatically on the site after deployment. This Markdown index is a human-readable snapshot; regenerate it whenever editing the JSON.

Existing artwork thumbnails come from the user’s own GitHub gallery. For new Nova pairings, the website shows separate external class and boss artwork. Unknown historical boss names are marked for verification instead of invented.

**Legend:** Approved = explicitly accepted; Previously created/explored = earlier work exists without a current verified final lock; Needs verification = gallery/history exists but boss cannot be confirmed confidently.

## Source and update policy

- Edit `planning/maplestory-pairings.json` to add or modify a pairing; the website reads it directly.
- Regenerate this Markdown index after JSON changes, to preserve a human-readable view.
- Do not record suggested new boss options as final approved without user approval.
- A hero appearing in a published gallery is **not** alone proof of an exact boss identity.
- Nova’s Magnus repeat (Kaiser and Cadena) is intentionally approved.
- No cubby-versus-island selection, artwork status, or signature-skill metadata is tracked here.
- New external hero and boss artwork is hotlinked only and credited through links to its source.
